COACH META MIND

Plataforma de Coaching con IA para League of Legends

SISTEMA EN ESTADO DE PRODUCCIÓN (100% OPERATIVO)

La Visión: Arquitectura de 3 Fases

Hemos construido un sistema de alto rendimiento que integra tu identidad de jugador (Astrología y Perfil) con la inteligencia artificial más avanzada (Gemini) y los datos en tiempo real de Riot Games y el Cliente LCU. El sistema opera en un ciclo continuo de tres fases críticas:

  • FASE I: Análisis de Perfil y Preparación

    La IA evalúa tu estilo de juego, basándose en tu signo zodiacal y tu historial de maestría, para ofrecerte recomendaciones de campeones sinérgicos o de desarrollo. Además, prepara desafíos semanales personalizados para el crecimiento a largo plazo.

  • FASE II: Coaching en Tiempo Real (La Ventaja Crítica)

    Activado por la detección del cliente LCU, este módulo ofrece:

    • Selección de Campeón: Consejos de draft, estrategia inicial y pre-inyección de runas optimizadas.
    • Partida en Vivo: Consejos tácticos en un overlay transparente (Nano Banana) que se adapta a tu arquetipo zodiacal.
    • Inyección de Runas: Habilidad de ejecutar comandos directos al cliente LCU para cargar páginas de runas instantáneamente.

  • FASE III: Evaluación Post-Partida

    Tras la partida, la IA analiza las métricas clave del historial para identificar 2 fortalezas y 2 debilidades, vinculando al menos una a tu perfil psicológico (zodiacSign), proporcionando una ruta clara para la mejora continua.

Arquitectura y Consistencia

El proyecto se entrega con dos componentes principales totalmente compatibles y un flujo de comunicación seguro y asíncrono.

1. Backend (Next.js API y Base de Datos) COMPLETO

  • Stack: Next.js (Routing/API), PostgreSQL (Base de Datos), postgres.js (Driver optimizado).
  • Seguridad: Autenticación JWT y hasheo de contraseñas con bcryptjs. Todas las peticiones AI están detrás de esta autenticación.
  • AI Engine: Gemini (v2.5-flash-lite) configurado para inyectar responseMimeType: "application/json" para asegurar la estabilidad y el formato de las respuestas.
  • Data Flow: Recibe los datos del cliente Electron a través del endpoint /api/live-game/update para persistir el estado del juego.

2. Aplicación de Escritorio (Electron) COMPLETO

  • Framework: Electron (para Desktop shell) y React/Next.js (para la interfaz de usuario).
  • LCU Core (lol-client-api.js): Módulo robusto encargado de:
    1. Detectar el Cliente LoL y obtener credenciales vía PowerShell.
    2. Manejar el polling continuo (pollLcuDataAndSend) para actualizar el Dashboard y el Overlay simultáneamente.
    3. Ejecutar comandos LCU para la inyección de runas (sendLcuCommand).
  • Manejo de Ventanas: Flujo controlado de Splash → Login → Dashboard + OverlayWindow (creada en el login exitoso para asegurar la sincronización).
  • Riot API Key: El manejo es seguro. La clave se guarda en la Electron Store después del Login/Profile Fetch y se usa exclusivamente en el lol-client-api.js del proceso principal.
